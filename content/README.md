# Portfolio content

This directory will contain the Markdown and YAML sources described in the [content model](../docs/content-model.md).

P0 establishes syntax validation. P1 has introduced `site.yaml` with a schema, parser, and server-only loader. Its contact and link values are temporary examples, not final public details. Profile, project, experience, and credit contracts are still pending. Final portfolio copy is a separate content task.

Do not place credentials, provider configuration, application state, or uploaded assets here. Portfolio images belong in `public/images`; selectable wallpapers belong together in `public/wallpapers` when those assets are introduced.
